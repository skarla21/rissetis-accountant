# Αναφορά SEO — giorgosrissetis.gr

Ημερομηνία: 3 Νοεμβρίου 2026

## Τι έλειπε / τι δεν δούλευε καλά

- Η ιστοσελίδα άνοιγε κατά προτεραιότητα στα **αγγλικά** (`/` → `/en`).
- Τίτλοι, περιγραφές και canonical ήταν ίδια για όλες τις γλώσσες και όχι στοχευμένα.
- Τα αναλυτικά κείμενα υπηρεσιών εμφανίζονταν μόνο σε modal (κλικ) — το Google συχνά δεν τα διάβαζε.
- Τα άρθρα φόρτωναν μόνο στο browser (client-side) — συχνά κενή ενότητα για crawlers.
- Ο χάρτης ιστοτόπου υπήρχε αλλά **δεν είχε υποβληθεί** στο Google Search Console.
- Η σελίδα admin ήταν ευρετηριάσιμη.
- Structured data υπήρχε (AccountingService) αλλά χωρίς geo / sameAs / areaServed.

## Τι διορθώθηκε στον κώδικα

1. Προεπιλεγμένη γλώσσα **ελληνικά** (`defaultLocale: el`, `/` → `/el`, `x-default` → ελληνικά).
2. Ξεχωριστά meta title/description/canonical/hreflang για `/el` και `/en`.
3. Υπηρεσίες: περίληψη + πλήρες κείμενο στο HTML (`<details>`), ορατό σε crawlers.
4. Άρθρα: φόρτωση metadata από τον server (ISR 24ωρών) — τίτλοι στο αρχικό HTML.
5. Εμπλουτισμός JSON-LD (διεύθυνση, geo, social, περιοχή εξυπηρέτησης).
6. Ανανέωση `sitemap.xml` και `robots.txt` (αποκλεισμός `/admin`).
7. `noindex` στη σελίδα admin.
8. Font με ελληνικό subset· βελτιωμένα alt κειμένων εικόνων.
9. Enrichment κειμένου προφίλ (Παγκράτι / Αθήνα / λογιστής).

## AEO (Answer Engine Optimization) — 3 Νοεμβρίου 2026

Στόχος: καλύτερη εμφάνιση σε απαντήσεις AI (Google AI Overviews / AI Mode, ChatGPT search, Perplexity), πάνω στη βάση του SEO.

### Τι προστέθηκε στον κώδικα

1. Ορατή ενότητα **Συχνές ερωτήσεις** (`#faq`) με απαντήσεις πρώτης πρότασης για διεύθυνση, ωράριο, υπηρεσίες, μισθοδοσία/δηλώσεις, περιοχή εξυπηρέτησης, ραντεβού.
2. Answer-first κείμενα στο προφίλ και στις περιλήψεις υπηρεσιών.
3. JSON-LD `@graph`: `AccountingService` + `Person` (Γιώργος Ρισσέτης) + `FAQPage`, με σταθερά `@id`.
4. `robots.txt`: ρητή άδεια για `OAI-SearchBot`, `ChatGPT-User`, `PerplexityBot`, `ClaudeBot` (χωρίς αποκλεισμό training bots).
5. `/llms.txt`: σύντομος χάρτης για agents — **δεν** επηρεάζει το Google Search / AI Overviews.

### Τι δεν κυνηγήσαμε (και γιατί)

- `llms.txt` / FAQ schema ως «κόλπο για citations» — το Google τα αγνοεί για generative AI· μελέτες δεν δείχνουν ουσιαστική αύξηση citations εντός ίδιου site.
- Ξεχωριστές λεπτές σελίδες ανά keyword — κίνδυνος scaled content, χωρίς ουσιαστική αξία για επισκέπτη.
- Article schema σε εξωτερικά άρθρα Taxheaven/gov.

### Ενέργειες μέτρησης (δικές σας)

1. Μετά το deploy: υποβολή sitemap + αίτημα ευρετηρίασης για `/el` (όπως παραπάνω).
2. Στο Search Console: αναφορά **Generative AI performance** (όταν είναι διαθέσιμη στον λογαριασμό).
3. Περιοδικός έλεγχος prompts σε ChatGPT / Perplexity / Google AI Mode:
   - «λογιστής Παγκράτι»
   - «λογιστικό γραφείο Φιλολάου»
   - «Ρισσέτης λογιστής»
